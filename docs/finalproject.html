challenge_data <- fromJSON("https://calvin-data304.netlify.app/data/swd-lets-practice-ex-2-13.json")

This data shows the completion rates for an email marketing campaign and also the response rate. The problem is that the response rate is low and the completion rate is high, but the completion rate comes from the total people who responded, so it shouldn’t be more than the response rate. There should be a new variable that calculates the completion rate with respect to the response rate. So how many people actually completed the survey, under the amount of people that actually responded.

challenge_data <- challenge_data |>
  separate(Date, into = c("quarter", "year"), sep = "-") |>
  mutate(
    quarter = parse_number(quarter),
    year = parse_number(year),
    date_str = paste0(year, "-", 3 * quarter - 2, "-01" ),
    date = ymd(date_str))
  
challenge_data <- challenge_data |> mutate(TrueCompletionRate = `Completion Rate` * `Response Rate`)

c

This graph tells a story about women’s fertility rates, contraception use, and unmet family planning needs in Tanzania over time.

Fertility Rate (Blue Line): The fertility rate has declined steadily from around 6 children per woman in the early 1990s to around 5 in the 2010s. This suggests improvements in reproductive health education, economic factors, and possibly access to family planning services.

Contraception Use (Red Line): The use of contraception has gradually increased over time, though it looks like it remains relatively low compared to fertility rates, we must remember that it is a proportion, so it only goes up to 1. This could indicate increased awareness and availability of contraceptive methods.

Unmet Family Planning Needs (Orange Line): The unmet need for family planning appears relatively low and stable over the years. If this line is declining, it suggests that more women are gaining access to the contraception they need. However, if it remains constant or rises, it indicates persistent barriers.

The declining fertility rate is possibly influenced by increasing contraception use and improved family planning services. However, unmet family planning is still relatively stable, meaning there might still be cultural, economic, or logistical barriers limiting access to some families.

penguins <- fromJSON("https://raw.githubusercontent.com/vega/vega-datasets/refs/heads/main/data/penguins.json")
penguinsplot <- vl_chart(penguins) |>
  vl_add_properties(title = "Penguin Measurements Interactive Plot") |>
  vl_mark_point() |>
  vl_encode_x("Beak Length (mm):Q", title = "Beak Length (mm)", scale = list(domain = list(20, 90))) |>
  vl_encode_y("Flipper Length (mm):Q", title = "Flipper Length (mm)", scale = list(domain = list(170, 240))) |>
  vl_encode_size("Body Mass (g):Q", title = "Body Mass (g)") |>
  vl_encode_color(
    "Species:N",
    title = "Species",
    scale = list(
      domain = list("Adelie", "Gentoo", "Chinstrap"),
      range = list("steelblue", "goldenrod", "tomato")
    )
  ) |>
  vl_encode_tooltip_array(list(
    "Beak Length (mm)",
    "Flipper Length (mm)",
    "Body Mass (g)",
    "Island",
    "Species"
  ))

penguinsplot |>
  vl_add_parameter("width", value = 200) |>
  vl_add_parameter("height", value = 200) |>
  vl_bind_range_input("width", min = 100, max = 400, step = 1) |>
  vl_bind_range_input("height", min = 100, max = 400, step = 1) |>
  vl_add_properties(
    width = list(expr = "width"),
    height = list(expr = "height")
  ) |>
  vl_add_parameter("Island", value = "All") |> 
  vl_bind_select_input(
    parameter_name = "Island",
    name = "Island: ",
    options = list("All", "Torgersen", "Dream", "Biscoe")
  ) |>
  vl_filter("Island == 'All' || datum.Island == Island")|>
  vl_add_point_selection(
    "species_param",
    bind = "legend",
    encodings = list("color")
  ) |>
  vl_add_point_selection(
    "size_param",
    bind = "legend",
    encodings = list("size")
  ) |>
  vl_encode_opacity(value = 0.2) |>
  vl_condition_opacity(param = "species_param", value = 1) |>
  vl_condition_opacity(param = "size_param", value = 1)

I chose a scatterplot because it best represents the data I’m trying to encode. Both beak length and flipper length are quantitative variables, so a scatterplot is the most effective way to display their relationship. I made sure that the scale for both axes remains consistent even when zooming in, ensuring that the jump between each point is the same. Since both variables are measured in millimeters, I kept the scales aligned for accurate visual comparison.

I chose not to start the axes at zero, and that’s okay because this is a scatterplot, not a bar chart, where starting at zero is necessary for comparing proportions. The key was maintaining the same scale for both axes so the comparison remains meaningful.

I added interactive legends and tooltips to make the graph more engaging and informative. Just by hovering over a few dots, we can quickly access a lot of information, which is helpful since many of the points are clustered in one area. The interactive legend also allows for adjusting the visibility of different species and body mass sizes. By adding opacity adjustments, the graph becomes more readable—areas with higher point density appear darker, making it easier to see where most data points are concentrated.

I considered other visualizations, such as using facet plots by island or a heatmap, but I felt that a scatterplot was the clearest way to show the relationships between these variables. The facets would have separated the data too much, making it harder to compare species across islands, and a heatmap wouldn’t have captured the individual data points as effectively.

```{r}
  vl_condition_opacity(param = "size_param", value = 1)

```


I chose a scatterplot because it best represents the data I’m trying to encode. Both beak length and flipper length are quantitative variables, so a scatterplot is the most effective way to display their relationship. I made sure that the scale for both axes remains consistent even when zooming in, ensuring that the jump between each point is the same. Since both variables are measured in millimeters, I kept the scales aligned for accurate visual comparison.

I chose not to start the axes at zero, and that’s okay because this is a scatterplot, not a bar chart, where starting at zero is necessary for comparing proportions. The key was maintaining the same scale for both axes so the comparison remains meaningful.

I added interactive legends and tooltips to make the graph more engaging and informative. Just by hovering over a few dots, we can quickly access a lot of information, which is helpful since many of the points are clustered in one area. The interactive legend also allows for adjusting the visibility of different species and body mass sizes. By adding opacity adjustments, the graph becomes more readable—areas with higher point density appear darker, making it easier to see where most data points are concentrated.

I considered other visualizations, such as using facet plots by island or a heatmap, but I felt that a scatterplot was the clearest way to show the relationships between these variables. The facets would have separated the data too much, making it harder to compare species across islands, and a heatmap wouldn't have captured the individual data points as effectively.
